## Как читать

- **Приоритет** — качественная оценка (спрос × связь с модулем × простота), а не частотность. Реальные цифры спроса **не собирались**: перед написанием каждую статью и термин проверить в Яндекс Wordstat (точная частотность "!слово") и по подсказкам.
- **Модуль** — slug лендинга Титло, куда ведёт внутренняя ссылка из статьи/термина (26 публичных модулей).
- **«N&L»** в запросе пользователя не расшифрован. Вероятные кандидаты помечены ⚑: NLP, LSI-слова, noindex / nofollow, N-граммы, леммы. Уточнить у автора запроса.

## Предложение по структуре и внедрению (по текущему коду)

- **Маршруты:** `/glossary/` — хаб A–Я с якорями букв и фильтром по категориям; `/glossary/[slug]/` — страница термина (300–800 слов: определение в 1–2 предложения, пример, «как проверить» с CTA в модуль, связанные термины). Статьи — `/blog/[slug]/`; сейчас в `next.config.ts` стоит постоянный (308) редирект `/blog` и `/blog/` → `/news/` — при запуске блога его убрать (или взять `/stati/`, если не хочется трогать старый редирект, который поисковики могли запомнить). Термины P3 — только якорная карточка в хабе, без отдельной страницы, чтобы не плодить тонкий контент.
- **Данные:** `lib/content/glossary.ts` (`slug, term, aliases, category, priority, moduleSlugs, related, short, body`) по образцу `lib/content/news.ts`; рендер переиспользует `components/NewsArticle.tsx` (типографика, хлебные крошки, CTA).
- **SEO:** `generateMetadata` + `canonicalMetadata()` из `lib/seo.ts`; JSON-LD: хаб — `DefinedTermSet`, термин — `DefinedTerm` + `BreadcrumbList` (+ `FAQPage`, если есть вопросы), статьи — `Article`/`BlogPosting` с `author`/`datePublished`/`dateModified`; OG-картинки через уже готовый `lib/og/render.tsx`. Добавить в `app/sitemap.ts`.
- **Перелинковка:** термин ↔ модуль (на лендинге модуля блок «Термины» из `moduleSlugs`), термин ↔ статьи, автоссылки на первое упоминание термина в статьях. В футер добавить ссылки «Глоссарий» и «Блог».
- **Порядок:** сначала 20 терминов из топа + хаб, потом 10 статей из топа контент-плана, затем P1-термины волнами по 20–30.
