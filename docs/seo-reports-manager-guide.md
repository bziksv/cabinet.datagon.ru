# SEO отчёты — как собрать отчёт (для менеджера)

1. Откройте **SEO отчёты** и создайте проект (wizard: домен → интеграции → шаблон → KPI).
2. В **Настройках** проверьте Метрику, мониторинг, цели Метрики, KPI и состав секций.
3. Нажмите **Сгенерировать отчёт**, выберите период.
4. Дождитесь статуса «Готов», отредактируйте тексты работ / рекомендации (можно вставлять фразы).
5. Нажмите **Опубликовать** — после этого клиент откроет публичную ссылку.
6. Отправьте ссылку email’ом, приложите PIN при необходимости; для созвона — **режим презентации** или `?lite=1`.
7. Экспорт: **PDF**, **пакет ZIP** (PDF+CSV), **CSV позиций**.
8. Перегенерация сохраняет предыдущую версию; **Клонировать** переносит тексты на новый период.

Типичные предупреждения до генерации: нет Метрики / мониторинга / целей / KPI — закройте их в настройках проекта.
